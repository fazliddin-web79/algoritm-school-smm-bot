# Algoritm School AI SMM Bot

Telegram orqali xom matn, foto yoki videodan tayyor post yaratadi. Administrator postni qayta yozdirishi, bekor qilishi yoki `@algoritm_school_oltiariq` kanaliga chiqarishi mumkin.

## Sozlash

1. Node.js 20 yoki yangiroq versiyasini o‘rnating.
2. `.env.example` faylidan `.env` nusxa yarating.
3. `.env` ichiga BotFather tokeni, OpenAI API kaliti va Telegram ID raqamingizni kiriting.
4. Botni kanalga administrator qilib qo‘shing va post joylash huquqini bering.
5. Quyidagilarni ishga tushiring:

```bash
npm install
npm start
```

## Telegram ID ni olish

Telegramdagi `@userinfobot` botiga yozib, raqamli ID ni oling. Uni `ADMIN_TELEGRAM_ID` sifatida kiriting.

## Xavfsizlik

`.env` faylini hech kimga yubormang va GitHub'ga yuklamang.
